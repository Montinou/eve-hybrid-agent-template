# Release checklist (customize per project)

- [ ] Typecheck passes on the release branch.
- [ ] Test suite passes; no skipped tests introduced by this release.
- [ ] No TODO/FIXME added in the diff against the previous release tag.
- [ ] Dependency lockfile is in sync with the manifest.
- [ ] No secrets, tokens or credentials in the diff.
- [ ] CHANGELOG (or release notes source) mentions every user-facing change.
